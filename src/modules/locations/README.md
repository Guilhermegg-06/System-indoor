# Locais
`location.types.ts` define `Location`, `LocationType` e `Position3D` para a DATA-01 (#28).
O catálogo de seis exemplos está em `src/data/locations.mock.ts`. `nodeId` permite
a associação com os grafos fictícios, enquanto `id` identifica o registro do catálogo.
Nomes, andares, setores e eventuais posições são dados de desenvolvimento.
